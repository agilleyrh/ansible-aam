# OpenShift Operator scaffold

This directory is a **future** Operator SDK / OLM packaging path (`AAMInstance` CRD + RBAC).

It does **not** deploy Advanced Automation Manager today. The manager image is a placeholder and there is no reconciler.

**To install AAM on OpenShift or laptop MicroShift, use [../openshift/README.md](../openshift/README.md).**

```bash
./deploy/openshift/deploy.sh
```
